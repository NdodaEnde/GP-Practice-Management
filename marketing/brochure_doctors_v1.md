## SurgiScan EHR — clinical records that file themselves.

### **The problem you know too well**

You see 30 patients a day. Each one's notes live somewhere different —
the paper file on your desk, the script pad, a sticky note from reception.
At 7pm you're still typing, still hunting for that one diagnosis, still
copying ICD-10 codes off a list so medical aid claims don't bounce.

### **What SurgiScan does**

Scan your handwritten consult notes. SurgiScan reads them, codes them,
links them to the patient record. **You review for 30 seconds and
click Approve.** The full structured record — diagnoses, prescriptions,
vitals, allergies — lands in the patient's file in under two seconds.

---

### **Three things that actually save time**

**1. ICD-10 codes inferred automatically**
"URTI" → J06.9. "HTN" → I10. "T2DM" → E11.9. 65 SA-GP
abbreviations pre-mapped to WHO codes. The codes are on every diagnosis
the moment you approve — your medical aid claims go out same-day.

**2. NAPPI codes on every prescription**
Type "Atenolol" or "Adco-Simvastatin"; we resolve to the NAPPI code and
generic name automatically. Brand-first match, generic fallback. Works
for both real-NAPPI prescriptions and OTC items.

**3. Patient match-or-create that doesn't make duplicates**
SA ID number exact match first, then surname + DOB. If we can't find
the patient, we create one — and flag it so reception can verify next
visit. No more two-Mrs-Mokoenas in your database.
